# Architecture Decision Records

ADRs registram decisões arquiteturais que afetam múltiplos módulos ou o futuro da plataforma.

## Estados

- Proposta: em discussão.
- Aceita: regra vigente.
- Substituída: outra ADR tomou seu lugar.
- Rejeitada: avaliada e não adotada.

## Índice

| ADR | Título | Status |
|---|---|---|
| ADR-0001 | Modular monolith como arquitetura da aplicação | Aceita |

Use 0000-template.md para novas decisões. Não altere retroativamente uma ADR aceita para esconder mudança de decisão; crie outra ADR e marque a anterior como substituída.
